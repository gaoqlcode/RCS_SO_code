# RCS 处理库接口使用说明

面向二次开发：链接 `librcs_proc.so`，包含头文件 `rcs/rcs_api.h` 即可。  
语言约定：**C++11**，不强制命名空间；不依赖 Qt。

---

## 1. 能做什么

| 接口 | 作用 |
|------|------|
| `processHrrp` | 高分辨距离像：合并 dat → 脉压 → 定标 → 写出 `.hrrp` / `.pdat` |
| `processRcs` | 二维 RCS：脉压 + 方位压缩 → 选角反/目标 → `.pdat` / `.rcs` |
| `processMosaic` | 多幅灰度 TIFF（或 RAW）拼接，可选匀光 |
| `flattenMosaic` | 对已有拼接 TIFF 单独匀光 |
| `listMosaicTiffs` | 列出目录下可用于拼接的 TIFF |
| `loadMosaicGrayPreview` | 读灰度预览（降采样），给界面选偏移用 |
| `prepareMosaicInputs` | 手动拼接前整理输入（有 TIFF 直接用，只有 RAW 先转） |
| `rcsVersion` | 库版本字符串 |

批处理 / 无界面时：把请求里的 `autoPick` 设为 `true`，不必实现选点回调。

---

## 2. 头文件

```text
include/rcs/
  rcs_api.h      // 入口函数
  types.hpp      // 请求/响应/选点结构
  callbacks.hpp  // 进度、取消、选点回调
  export.h       // 导出宏（一般不用改）
```

包含方式：

```cpp
#include "rcs/rcs_api.h"
```

编译时加 `-I<path_to_sdk>/include`，链接 `-L<path_to_sdk>/lib -lrcs_proc`，并保证运行时能找到 `librcs_proc.so`。  
交付包已将 libtiff **静态编入** `librcs_proc.so`，客户**不必**再 `apt install libtiff5`。

## 3. 通用回调 `Callbacks`

```cpp
struct Callbacks {
    std::function<void(int, const std::string &)> onProgress; // 0~100 + 说明
    std::function<bool()> isCancelled;                        // 返回 true 则中止
    std::function<void(const std::string &)> onMessage;
    std::function<void(const std::string &)> onError;

    // HRRP：确认角反峰（可改距离）
    // RCS：选角反 / 选目标
    // …详见 callbacks.hpp
};
```

不需要的回调留空即可。错误信息也会通过函数返回值的 `err` 字符串带回。

## 4. HRRP

### 请求 `HrrpRequest`

| 字段 | 含义 | 默认 |
|------|------|------|
| `dataFolder` | 含 `*_L0_HH.dat` 等原始数据的目录 | 必填 |
| `pol` | 极化，如 `HH` | `"HH"` |
| `tgtName` | 目标名（写文件名用） | `"目标"` |
| `outDir` | 输出目录；空则落到数据目录下 `处理结果_HRRP_HH` | |
| `sigmaTheoryDb` | 角反理论 RCS（dBsm） | `18.25` |
| `cropN` | 距离向裁剪点数 | `8192` |
| `phaseMode` | 相位处理模式 | `0` |
| `autoPick` | `true`：自动用功率峰，不回调选点 | `false` |

### 响应 `HrrpResponse`

- `rangeM` / `rcsDbsm` / `phaseDeg`：曲线数据
- `hrrpPath` / `pdatPath`：写出文件路径

### 交互选点（`autoPick=false`）

实现 `onCornerConfirm`：入参为距离轴、功率 dB 曲线、自动峰下标；可把  
`sel.cornerRangeOverrideM` 设成确认后的距离（米），`<0` 表示沿用自动峰。  
回调返回 `false` 表示取消。

### 示例

```cpp
HrrpRequest req;
req.dataFolder = "/data/xxx";
req.pol = "HH";
req.outDir = "/tmp/hrrp_out";
req.autoPick = true;

Callbacks cb;
cb.onProgress = [](int p, const std::string &m) {
    std::cerr << p << "% " << m << "\n";
};

HrrpResponse resp;
std::string err;
if (!processHrrp(req, resp, cb, &err)) {
    std::cerr << "失败: " << err << "\n";
} else {
    std::cerr << "写出: " << resp.hrrpPath << "\n";
}
```

## 5. RCS

### 请求 `RcsRequest`

在 HRRP 同类字段之外：

| 字段 | 含义 | 默认 |
|------|------|------|
| `azMode` | `1` 条带 / `2` 聚束 | `2` |
| `vSar` | 平台速度相关参数（m/s 量级，按现网习惯） | `10` |
| `autoPick` | `true`：角反用距离峰、方位取中间；目标也走自动逻辑 | `false` |

### 响应 `RcsResponse`

- `targets`：各目标 RCS、视角、距离、是否有效、标签
- `pdatPath` / `rcsPath`
- `rangeM` / `profileDbsm`：剖面（有则填）

### 交互选点

- `onCornerPick`：预览灰度图 + 全分辨率行列；往 `sel.corners` 填 `InteractPick(az, rg)`（**全分辨率下标**）
- `onTargetPick`：点目标填 `sel.targets`；扩展目标设 `targetMode=2`，填 `extendedRanges`（距离米，起止）

## 6. 拼接 Mosaic

### 请求 `MosaicRequest`

| 字段 | 含义 |
|------|------|
| `inFolder` / `outFolder` | 输入图目录 / 输出目录 |
| `doFlatten` | 是否匀光 |
| `medOut` | 匀光中值目标（经验默认 `0.35`） |
| `mode` | `0` 自动配准；`1` 使用下面的偏移 |
| `offR` / `offC` | 各图相对偏移（行/列），`mode==1` 时用 |
| `rawNrHint` / `rawNaHint` | 仅 RAW 输入时可选尺寸提示，没有可填 `0` |

### 响应

- `mosaicTif` / `flattenTif` / `displayTif` / `offsetsCsv`
- `seamCols`：接缝列，给后续匀光用

手动偏移流程常见写法：

1. `prepareMosaicInputs` 得到 TIFF 列表  
2. `loadMosaicGrayPreview` 给界面排版  
3. 填好 `offR`/`offC`，`mode=1`，再 `processMosaic`

---

## 7. 错误与取消

- 函数返回 `false` 时看 `err`（若传入非空指针）
- `isCancelled` 返回 `true` 时链路尽快退出，错误串多为 `"已取消"`
- 不要在回调里做很重的事阻塞太久；界面建议把选点放到 UI 线程，用同步等待交给库线程

---

## 8. 线程与链接注意

- 同一时刻对同一输出目录并发跑多路处理不保证安全，建议串行或分目录
- Linux 运行时只需能解析到 `librcs_proc.so`（libtiff 已静态编入，无需系统 libtiff5）
- Windows 交付需另行交叉/本机编译 DLL；当前包内 `.so` 为 **Linux x86_64**
