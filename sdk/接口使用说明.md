# RCS 处理库接口说明

C++11，不绑 Qt。流程：填请求 → 回调里选点/框选 → `process*`。完整 SDK 含大图拼接。

## 功能分组

| 组 | 功能 | 主接口 |
|----|------|--------|
| [0] | 通用 | `rcsVersion` |
| [1] | HRRP 一维距离像 | `processHrrp` |
| [2] | RCS 测量 | `processRcs` |
| [3] | 点频 RCS | `processCwRcs` |
| [4] | 后向散射 σ⁰ | `processSigma0` |
| [5] | 0 级预览 | `previewL0Folder` / `previewL0File` |
| [6] | 数据探查 / 路径 | `listL0Files`、`probe*`、`parseImagedRawSize`、`defaultOutDir`… |
| [7] | RAW 预览辅助 | `loadImagedRawPreview`、`mapPreview*` |
| [8] | 大图拼接 | `processMosaic`、`flattenMosaic`、`listMosaicTiffs`、`loadMosaicGrayPreview`、`prepareMosaicInputs` |
| [9] | RCS 像辐射定标 | `processRcsCalTif` |
| [10] | 源 DAT → 四极化 L0 → SAR/ISAR 成像（Linux） | `processZeroImage`、`processZeroImageFolder`（`kind` 0=SAR，1=ISAR）、`zeroImageSidecarPath` |

交付某套功能时，在头文件中保留对应组即可；未交付的组不要给甲方调用。详见 `README.md`。

## 例子

```cpp
#include "rcs/rcs.hpp"

HrrpRequest req;
req.dataFolder = "/data/in";
req.outDir = "/data/out";
// autoPick 默认 false，要接 onCornerConfirm

Callbacks cb;
cb.onProgress = [](int p, const std::string &m) { /* 进度 */ };
cb.isCancelled = []() { return false; };
cb.onCornerConfirm = [](const std::vector<double> &R,
                        const std::vector<double> &profileDb, int peakIdx,
                        InteractSelection &sel) {
    // 弹窗确认峰距，写 sel.cornerRangeOverrideM；取消 return false
    return true;
};

HrrpResponse resp;
std::string err;
if (!processHrrp(req, resp, cb, &err)) { /* err */ }
// 画图用 resp.rangeM / resp.rcsDbsm
```

```bash
g++ app.cpp -I/path/to/sdk/include -L/path/to/sdk/lib -lrcs_proc \
    -Wl,-rpath,/path/to/sdk/lib -pthread -o app
```

## 接口与回调

业务都要带 `Callbacks&`：

| 接口 | 组 | 回调 | 画图 / 结果 |
|------|----|------|-------------|
| `processHrrp` | [1] | `onCornerConfirm` | `rangeM` / `rcsDbsm` |
| `processRcs` | [2] | `onCornerPick`、`onTargetPick` | `targets`；选点带 `GrayImage` |
| `processCwRcs` | [3] | `onCornerConfirm`、`onTargetPick` | `freqGHz` / `rcsDbsm` |
| `processSigma0` | [4] | `onRectRoi`、`onTargetRois` | 预览 + `.cs` |
| `previewL0Folder` / `previewL0File` | [5] | 进度即可 | 时域/频域 |
| `processMosaic` | [8] | 进度 / 取消 | `mosaicTif` / `displayTif` / 匀光 TIFF / `l3Path` |
| `processRcsCalTif` | [9] | `onRectRoi`(角反缓冲) | `K` + 固定 `*_RCS_dBsm.tif` + 三级 `.txt` |

默认 `autoPick=false`。常量在 `namespace rcs`（如 `AzSpotlight`、`Sigma0BgRing`）。

## 界面侧注意

- 库调用放工作线程，别卡 UI  
- 选点回调里切回主线程弹窗，等用户结果再 return  
- 取消读 `isCancelled`  
- 曲线/图像自己画，SDK 只给 `vector` / `GrayImage`  
- 路径 UTF-8  

例子：`demo/cli_demo`、`demo/gui_demo`。

## Callbacks

| 成员 | 用途 |
|------|------|
| `onProgress` / `onMessage` / `onError` | 进度、日志 |
| `isCancelled` | 取消 |
| `onCornerConfirm` | HRRP / 点频核对角反峰 |
| `onCornerPick` / `onTargetPick` | RCS / 点频选点 |
| `onRectRoi` / `onTargetRois` | 后向散射框选 |

不用的留空。

## 请求字段

HRRP / RCS / 点频：`dataFolder`、`pol`、`outDir`（空则库建默认目录）。  
Sigma0：`rawPath`、`nr`/`na`（可 `parseImagedRawSize`）；交互时不用预填 ROI。  
拼接：`inFolder`、`outFolder`；`mode=0` 自动配准，`mode=1` 用 `offR`/`offC`。

`rcs/rcs.hpp`（总头）、`rcs_api.h`、`types.hpp`、`callbacks.hpp`、`export.h`。
