# RCS 处理库接口说明

C++11，不绑 Qt。流程：填请求 → 回调里选点/框选 → `process*`。不含大场景拼接。

## 例子

```cpp
#include "rcs/rcs.hpp"

HrrpRequest req;
req.dataFolder = "/data/in";
req.outDir = "/data/out";
// autoPick 默认 false，要接 onCornerConfirm

Callbacks cb;
cb.onProgress = [](int p, const std::string &m) { /* 进度 */ };
cb.isCancelled = []() { return false; };
cb.onCornerConfirm = [](const std::vector<double> &R,
                        const std::vector<double> &profileDb, int peakIdx,
                        InteractSelection &sel) {
    // 弹窗确认峰距，写 sel.cornerRangeOverrideM；取消 return false
    return true;
};

HrrpResponse resp;
std::string err;
if (!processHrrp(req, resp, cb, &err)) { /* err */ }
// 画图用 resp.rangeM / resp.rcsDbsm
```

```bash
g++ app.cpp -I/path/to/sdk/include -L/path/to/sdk/lib -lrcs_proc \
    -Wl,-rpath,/path/to/sdk/lib -pthread -o app
```

## 接口

业务都要带 `Callbacks&`：

| 接口 | 回调 | 画图数据 |
|------|------|----------|
| `processHrrp` | `onCornerConfirm` | `rangeM` / `rcsDbsm` |
| `processRcs` | `onCornerPick`、`onTargetPick` | `targets`；选点带 `GrayImage` |
| `processCwRcs` | `onCornerConfirm`、`onTargetPick` | `freqGHz` / `rcsDbsm` |
| `processSigma0` | `onRectRoi`、`onTargetRois` | 回调里有预览；结果 `.cs` |
| `previewL0Folder` / `previewL0File` | 进度即可 | 时域/频域 |

默认 `autoPick=false`。

探查：`listAvailablePolarizations`、`listL0Files`、`listImagedRawFiles`、`probeL0File`、`probeDataFolder`、`parseImagedRawSize`、`defaultOutDir`。  
预览辅助：`loadImagedRawPreview`、`mapPreviewRoiToFull`、`mapFullPointToPreview`。  
常量在 `namespace rcs`（如 `AzSpotlight`、`Sigma0BgRing`）。

## 界面侧注意

- 库调用放工作线程，别卡 UI  
- 选点回调里切回主线程弹窗，等用户结果再 return  
- 取消读 `isCancelled`  
- 曲线/图像自己画，SDK 只给 `vector` / `GrayImage`  
- 路径 UTF-8  

例子：`demo/cli_demo`、`demo/gui_demo`。

## Callbacks

| 成员 | 用途 |
|------|------|
| `onProgress` / `onMessage` / `onError` | 进度、日志 |
| `isCancelled` | 取消 |
| `onCornerConfirm` | HRRP / 点频核对角反峰 |
| `onCornerPick` / `onTargetPick` | RCS / 点频选点 |
| `onRectRoi` / `onTargetRois` | 后向散射框选 |

不用的留空。

## 请求字段

HRRP / RCS / 点频：`dataFolder`、`pol`、`outDir`（空则库建默认目录）。  
Sigma0：`rawPath`、`nr`/`na`（可 `parseImagedRawSize`）；交互时不用预填 ROI。

`rcs/rcs.hpp`（总头）、`rcs_api.h`、`types.hpp`、`callbacks.hpp`、`export.h`。
