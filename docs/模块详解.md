## 1. 工程总览

### 1.1 两套用法

| 用法 | 说明 |
|------|------|
| 完整工程 | 编 `lib` + `gui` + `cli`，可选拼接（`RCS_ENABLE_MOSAIC`） |
| 客户 SDK | 只拿 `sdk/include` + `sdk/lib`，界面自己做；**无拼接 API** |

本仓库 GUI 默认从源码链 `rcs_proc`（`RCS_USE_SDK=OFF`）。验证交付包时可 `RCS_USE_SDK=ON`（拼接会关）。

### 1.2 顶层目录

```text
RCS_SO_code/
  lib/                 # 处理库源码 → librcs_proc.so / .dll
    include/rcs/       # 完整头（含拼接声明）
    src/               # io / signal / hrrp / rcs / cw_rcs / sigma0 / l0_preview / mosaic ...
  gui/                 # Qt 产品界面「雷达数据处理软件」
  cli/                 # rcs_cli
  sdk/                 # 客户交付包（头 + 库 + 说明 + demo）
  scripts/             # build_linux.sh / build_win.ps1|.bat
  tests/               # 冒烟与功能测试
  3rdparty/            # 静态 libtiff（拼接用）
  docs/                # 本文档
```

### 1.3 库内处理链路（概念）

L0 `.dat` 业务大致顺序：

```text
列文件 → 合并/读帧 → 去直流/直达波 → 脉压 →（RCS）方位聚焦 → 定标 → 交互选点 → 写 L1/L2/L3 → 曲线回传
```

后向散射走**已成像 RAW**，不走 L0 脉压链。  
0 级预览只做时域幅度 + FFT 频谱，不落盘。

### 1.4 输出目录约定（各页统一）

规则：`输入基目录 / 处理结果_<标记>`。界面用 `gui/common/OutDirField`：

- 选输入路径后自动填默认输出；手改或浏览后保留  
- 换输入路径会重置为新的默认；换极化等 tag 时若仍是上次自动值则跟着变  
- 占位符形如 `数据文件夹/处理结果_HRRP_<极化>`  

| 业务 | 基目录 | 标记 |
|------|--------|------|
| RCS / HRRP / 点频 | L0 数据文件夹 | `RCS_<极化>` / `HRRP_<极化>` / `点频RCS_<极化>` |
| 后向散射 | RAW 所在目录 | `后向散射` |
| 拼接 | 输入图目录 | `拼接` |

库内 `lib/src/common/OutPath.h` 的 `resolveOutDir` / `*ResultTag` 与界面一致。

### 1.5 输入文件约定

| 类型 | 形态 | 用途 |
|------|------|------|
| 0 级 L0 | `*_L0_<极化>.dat`，极化如 `HH`/`HV`/`VV`/`VH` | HRRP / RCS / 点频 / 预览 |
| 成像 RAW | `uint16` 小端振幅；文件名含 `Nr`/`Na`，如 `Image_Nr2048Na4602....raw` | 后向散射 |
| 拼接 | TIFF / RAW 图目录 | 仅完整工程 mosaic |

路径在库内一律按 **UTF-8** 处理（Windows 下库内再转宽字符）。

## 2. 编译与打包

### 2.1 Linux 一键

```bash
./scripts/build_linux.sh              # 先编 rcs_proc → pack sdk → 再编 GUI/CLI
./scripts/build_linux.sh --clean      # 清 build_linux
./scripts/build_linux.sh --no-mosaic  # 关拼接
./scripts/build_linux.sh --no-gui     # 只编库和 cli
```

有 `3rdparty/install/linux_<架构>` 时默认开拼接。  
产物：`build_linux/bin/RCS`、`build_linux/cli/rcs_cli`、`sdk/lib/librcs_proc.so*`。  
**发布包**：`deploy/linux_<架构>/`（含运行时库，用 `./run_RCS.sh`）。

开发机直接跑：

```bash
export LD_LIBRARY_PATH=$PWD/build_linux/lib:$LD_LIBRARY_PATH
./build_linux/bin/RCS
```

发布目录（拷到别的机器）：

```bash
./deploy/linux_x86_64/run_RCS.sh    # 架构名以本机 uname -m 为准
```

WSL 中文方框：`sudo apt install fonts-wqy-microhei fonts-noto-cjk`。
### 2.2 Windows 一键（Qt MinGW 7.3）

```powershell
.\scripts\build_win.ps1
# 或 scripts\build_win.bat
```

要求：

- Qt：`C:\Qt\Qt5.12.8\5.12.8\mingw73_64`
- MinGW：`Tools\mingw730_64`
- `3rdparty\install\mingw73_64`（静态 libtiff）

脚本流程：结束占用进程 → 清 `build_win` → `RCS_USE_SDK=OFF` + 拼接 ON → 编 `rcs_proc` → `sdk\pack_sdk.bat` → 编完整工程 → **`deploy\win64\`**（windeployqt + MinGW 运行时）。  
MinGW 库名多为 `librcs_proc.dll`，打包脚本会同时拷成 `sdk\lib` 下可用名字。

发布：把 `deploy\win64\` 整夹拷走，双击 `RCS.exe`。  
若删不掉 `build_win`：先关 `RCS.exe`，别开着资源管理器进 `bin`。
### 2.3 CMake 开关

| 选项 | 默认 | 含义 |
|------|------|------|
| `RCS_USE_SDK` | OFF | ON：GUI/CLI 只链 `sdk/`，拼接强制关 |
| `RCS_ENABLE_MOSAIC` | 有静态 tiff 时 ON | 拼接库代码 + GUI Tab |
| `RCS_BUILD_GUI` / `CLI` / `TESTS` | ON | 是否编界面/命令行/测试 |
| `RCS_TIFF_PREFER_STATIC` | ON | tiff 打进 `rcs_proc`，客户少装系统库 |

改算法、要拼接：务必 `RCS_USE_SDK=OFF`。

### 2.4 打包 SDK

```bash
# Linux（默认看 build_linux）
export RCS_BUILD_DIR=build_linux   # 可选
./sdk/pack_sdk.sh
```

```bat
REM Windows
set RCS_BUILD_DIR=build_win
sdk\pack_sdk.bat
```

打包**只更新动态库**，头文件始终用 `sdk/include`（故意不含 `processMosaic`）。  
因此：开拼接编出来的 `.so/.dll` 给客户用业务接口没问题；客户头里看不到拼接。

### 2.5 软件发布目录 `deploy/`

与 SDK（给二次开发）不同：`deploy/` 是**可运行软件**（GUI + CLI + 运行时库）。

| 脚本 | 输出 |
|------|------|
| `scripts/deploy_linux.sh` | `deploy/linux_x86_64/` 或 `linux_aarch64/` 等 |
| `scripts/deploy_win.ps1` | `deploy/win64/` |

一键编译脚本末尾会自动调用。只重打发布包时单独跑上述脚本即可。

## 4. 通用约定与数据类型

### 4.1 调用约定

1. 业务入口都是 `bool process*(req, resp, Callbacks& cb, std::string *err)`。  
2. `false` = 失败或用户取消；可读原因写在 `*err`（可传 `nullptr`）。  
3. 默认 `autoPick=false`：必须接对应选点/框选回调。`true` 仅适合无 UI 冒烟。  
4. SDK **不画图**：曲线是 `std::vector<double>`，图像是 `GrayImage`，界面自己画。  
5. 库可在工作线程同步调用回调；UI 线程弹窗要用阻塞切回主线程（见第 5、13 节）。

### 4.2 坐标约定（容易踩坑）

| 场景 | 约定 |
|------|------|
| 图像点 `InteractPick` | `az` = 方位（脉冲）下标，`rg` = 距离门下标，从 0；**全分辨率** |
| `RectRoi` | `x` = 方位列，`y` = 距离行，`w/h` 宽高；**全分辨率** |
| 成像 RAW 磁盘布局 | 行主序 **`[Nr][Na]`**（距离行 × 方位列）。MATLAB 常 `fread([Na,Nr])'` 再存，读错会变成噪声图 |
| 预览图 | `loadImagedRawPreview` 降采样 8bit；框选后用 `mapPreviewRoiToFull` 转回全分辨率再交给库 |

### 4.3 命名常量（`namespace rcs`）

```cpp
AzStrip = 1, AzSpotlight = 2          // RCS 方位模式
TargetPoint = 1, TargetExtended = 2   // 点目标 / 扩展目标
Sigma0Area / Sigma0Point              // 后向散射目标类型
Sigma0BgNone / Sigma0BgRing / Sigma0BgRoi
Sigma0AnchorLastRow / Center / CrKnown
```

### 4.4 选点结果 `InteractSelection`

| 字段 | 含义 |
|------|------|
| `corners` | 角反点列表 |
| `targets` | 点目标列表 |
| `targetMode` | 1 点目标 / 2 扩展 |
| `extendedRanges` | 扩展目标距离起止（米） |
| `cornerRangeOverrideM` | HRRP/点频确认后的角反峰距离（米）；`<0` 表示用自动峰 |

### 4.5 `GrayImage`

`width` × `height`，`pixels[y*width + x]`，8bit 灰度。  
RCS 选点回调、后向散射框选回调都会带预览图。

## 5. Callbacks 交互模型

定义见 `sdk/include/rcs/callbacks.hpp`。

| 成员 | 何时用 |
|------|--------|
| `onProgress(int, string)` | 0～100 进度 |
| `onMessage` / `onError` | 日志；最终成败仍看返回值与 `*err` |
| `isCancelled()` | 返回 true 则库尽快停 |
| `onCornerConfirm` | HRRP、点频：核对角反功率峰曲线 |
| `onCornerPick` | RCS：在灰度预览上选角反（坐标写全分辨率） |
| `onTargetPick` | RCS、点频：选目标（点或扩展距离段） |
| `onRectRoi` | 后向散射：按 stage 框 noise/cal/bg |
| `onTargetRois` | 后向散射：一个或多个地物 ROI |

不用的成员留空即可。

### 5.1 推荐线程模型（产品 GUI）

```text
UI 线程                         Worker 线程
  |                               |
  |  startProcess                 |
  |------------------------------>|
  |                               | processHrrp(...)
  |                               |   onCornerConfirm 被库调用
  |  弹窗 / 等用户                 |<-- BlockingQueuedConnection --|
  |  provideSelection / return    |
  |------------------------------>|
  |                               | 继续算、写文件
  |  曲线 / finishedOk            |
  |<------------------------------|
```

要点：

- **不要**在 UI 线程直接跑 `process*`（会卡死）。  
- 选点回调里若直接 `QDialog::exec`，在 Worker 线程不安全；应 `QMetaObject::invokeMethod(..., BlockingQueuedConnection)` 切回 UI。  
- 取消：`requestCancel()` 应能从任意线程置位（本仓库 `ProcessWorker` 用 `atomic`，避免 QueuedConnection 堵在忙 Worker 上）。

`sdk/demo/gui_demo` 的 `ConfirmBridge` + `DemoWorker` 就是最小范本。

## 6. 模块：数据探查

源码：`lib/src/sdk_util/` 等；头文件：`rcs_api.h` 探查一节。

| API | 作用 |
|-----|------|
| `listAvailablePolarizations` | 目录里实际有哪些极化 |
| `listL0Files` | 某极化下 L0 文件名列表（按序号） |
| `probeL0File` | 单文件头 + 首帧元数据 |

`FileHeaderInfo` / `FrameMeta`：二次开发一般只展示，不必手填进处理请求。

## 7. 模块：0 级时域/频域预览

| 项 | 内容 |
|----|------|
| API | `previewL0Folder` / `previewL0File` |
| 库源码 | `lib/src/l0_preview/` |
| GUI | `gui/modules/l0_preview/` |
| 输入 | L0 目录 + 极化；脉冲号、采样率、是否去直流 |
| 输出 | 不落盘；`L0PulsePreviewItem` 曲线与峰值、90% 占用带宽 |

### 7.1 请求要点（`L0PreviewRequest`）

- `fsHz`：默认 `1.25e9`  
- `pulseNo`：从 1 起  
- `removeDC`：建议 true  
- `maxFiles`：`<=0` 全部；demo 可限制前几个加快调试  

### 7.2 单文件结果字段

| 字段 | 含义 |
|------|------|
| `tUs` / `amp` | 时域 |
| `fMHz` / `spectrumDb` | 频域（归一化 dB） |
| `ampPkUs` | 幅度峰时间 |
| `sig1Us`/`sig2Us` | 信号区估计 |
| `fPkMHz` / `occBwMHz` | 谱峰、90% 占用带宽 |

### 7.3 GUI 行为

预览一次把多文件结果放进内存，用「上一组/下一组」切换显示。  
曲线点数很大时，本仓库绘图控件会按像素抽稀，避免切换卡顿。

## 8. 模块：HRRP

| 项 | 内容 |
|----|------|
| API | `processHrrp` |
| 库源码 | `lib/src/hrrp/` + 共用 `io`/`signal` |
| GUI | `gui/modules/hrrp/` |
| 交互 | `onCornerConfirm`（默认） |
| 产物 | `.hrrp`（三级文本）、`.pdat` 等；曲线 `rangeM` / `rcsDbsm` / `phaseDeg` |

### 8.1 请求（`HrrpRequest`）

| 字段 | 说明 |
|------|------|
| `dataFolder` / `pol` | 输入 |
| `outDir` | 空则默认 `处理结果_HRRP_<极化>` |
| `tgtName` | 进文件名 |
| `sigmaTheoryDb` | 角反理论 RCS，默认 18.25 dBsm |
| `autoPick` | false：弹峰确认；true：自动峰（仅冒烟） |
| `cropN` | 距离向裁剪，默认 8192 |
| `phaseMode` | 一般 0 |

### 8.2 交互

库算出距离–功率曲线后调 `onCornerConfirm(rangeM, profileDb, peakIdx, sel)`：

- 界面展示曲线，允许改峰距离；  
- 写入 `sel.cornerRangeOverrideM`（米）；`<0` 用自动峰；  
- `return false` 取消整次处理。

### 8.3 画图

用 `resp.rangeM` 与 `resp.rcsDbsm`（及可选 `phaseDeg`）。路径在 `hrrpPath` / `pdatPath`。

## 9. 模块：RCS 测量

| 项 | 内容 |
|----|------|
| API | `processRcs` |
| 库源码 | `lib/src/rcs/` |
| GUI | `gui/modules/rcs/` |
| 交互 | `onCornerPick` → `onTargetPick` |
| 产物 | `.rcs` / `.pdat`；`resp.targets[]` |

### 9.1 请求要点（`RcsRequest`）

- `azMode`：`rcs::AzSpotlight`（2，默认）或 `AzStrip`（1）  
- `vSar`：条带模式平台速度 m/s  
- 其余同 HRRP：`dataFolder`/`pol`/`outDir`/`sigmaTheoryDb`/`cropN`/`autoPick`

### 9.2 交互顺序

1. **`onCornerPick`**：带 `GrayImage` 预览与 `fullNr`/`fullNp`。在图上点角反，坐标必须是**全分辨率** `az/rg`，写入 `sel.corners`。  
2. **`onTargetPick`**：再选目标。  
   - 点目标：`targetMode=1`，填 `targets`；  
   - 扩展：`targetMode=2`，填 `extendedRanges`（米）。

预览像素 ≠ 全分辨率下标。若只在预览图上点了像素，要按预览尺寸与 `fullNr/fullNp` 映射后再写入。

### 9.3 结果

`RcsTargetItem`：`rcsDbsm`、`azViewDeg`、`rangeM`、`valid`、`label` 等。  
可选剖面：`rangeM` / `profileDbsm`。

## 11. 模块：后向散射系数 σ⁰

| 项 | 内容 |
|----|------|
| API | `processSigma0` |
| 库源码 | `lib/src/sigma0/` |
| GUI | `gui/modules/sigma0/` |
| 输入 | **已成像** `uint16` LE `.raw`，不是 L0 |
| 交互 | `onRectRoi`（noise/cal/bg）+ `onTargetRois` |
| 产物 | 三级 `.cs`；`K`、各目标 `sigma0Db` 等 |

### 11.1 请求要点（`Sigma0Request`）

| 字段 | 说明 |
|------|------|
| `rawPath` | RAW 路径 |
| `nr` / `na` | 可用 `parseImagedRawSize` 从文件名解析 |
| `fcGHz` / `vs` / `incAngleDeg` / `hFlight` | 几何与雷达参数 |
| `sigmaTheoryDb` | 角反理论 RCS（dBsm），库内 `10^(dB/10)` 转线性 |
| `targetType` | 0 区域 / 1 点目标 |
| `bgMode` | 点目标背景：无 / 环 / 另框 ROI |
| `autoPick` | false：回调框选；true：用预填 `calBufRoi`/`targetRois` |
| `measureTime` | 写入产品头的时间字符串 |

### 11.2 框选 stage（`onRectRoi`）

| stage | 含义 |
|-------|------|
| `"noise"` | 可选噪声区；不框则直方图估噪 |
| `"cal"` | 角反缓冲区，一般必选 |
| `"bg"` | 背景（`bgMode` 需要时） |

写出的 `RectRoi` 必须是全分辨率。推荐：

```text
loadImagedRawPreview → 用户在预览上框 → mapPreviewRoiToFull → 填入回调 out
```

### 11.3 RAW 排布

磁盘：**行主序 `[Nr][Na]`**。  
读反成 `[Na][Nr]` 时预览像噪声、与参考相关性接近 0——这是历史踩坑点，加载与 `processSigma0` 已按正确布局。

## 13. GUI 架构

### 13.1 分层


### 13.2 各 Tab 与库 API 对应

| Tab | Worker 调用 |
|-----|-------------|
| 原始数据预览 | `previewL0Folder` |
| RCS测量 | `processRcs` |

### 13.3 共享输入 vs 统一输出

- **输入**：`SharedDataSession` 同步 L0 数据文件夹到 RCS/HRRP/点频/L0 预览。后向散射（RAW）、拼接（图目录）本页自管。  
- **输出**：各页一个 `OutDirField`，规则见上文「1.4 输出目录约定」。不要在 Page 里再抄 `outDirUserEdited_` 那一套。源码级说明见 [`源码导读.md`](源码导读.md) §2。

### 13.4 图标

- 窗口图标：`:/app.ico`（qrc）；`app.png` 须为真 PNG（曾误把 JPEG 命名为 png 导致不显示）。  
- Windows exe 图标：`gui/resources/rcs.rc` 嵌入 `app.ico`（CMake WIN32 已加入）。

## 15. 二次开发接入步骤

1. 拿到 `sdk/`（或本仓库执行 `pack_sdk`）。  
2. 工程加 include：`sdk/include`；链 `rcs_proc`；Linux 注意 `rpath`/`LD_LIBRARY_PATH`。  
3. `#include "rcs/rcs.hpp"`。  
4. 填 `XxxRequest`，组 `Callbacks`（进度 + 取消 + 该业务选点）。  
5. 工作线程调用 `process*`；选点回调里切 UI 线程阻塞等待。  
6. 用 `resp` 里的 vector / 路径画图或提示用户。  
7. 需要拼接：不要用客户 SDK 头，改链完整库并开 `RCS_ENABLE_MOSAIC`。

最小 HRRP 骨架见 `sdk/接口使用说明.md` 与 `sdk/demo/gui_demo`。

## 16. 常见问题

| 现象 | 原因与处理 |
|------|------------|
| 后向散射预览像噪声 | RAW 行列转置；必须按 `[Nr][Na]` 读 |
| 框选结果不对 | 预览坐标没转全分辨率；用 `mapPreviewRoiToFull` |
| 标题出现 `90%%` | `QString` 链式 `arg` 与 `%%` 转义问题；写单 `%` 或拆开拼字符串 |
| 切「下一组」很慢 | 曲线点数过大 + 抗锯齿全点绘制；已对绘图抽稀，需用新编 GUI |
| Windows 无 exe 图标 | 未嵌 `.rc` 或旧缓存；重编并刷新资源管理器 |
| WSL 中文方框 | 缺中文字体；装 `fonts-noto-cjk` / `fonts-wqy-microhei` |
| `RCS_USE_SDK=ON` 找不到库 | `sdk/lib` 无当前平台库（例如只有 Linux `.so`）；先本机编库再 pack，或关 `USE_SDK` |
| 客户头没有拼接 | 设计如此；拼接走完整工程 |
| 删不掉 `build_win` | `RCS.exe` 占用 Qt 插件 DLL；先结束进程 |
| 三级文本 `.hrrp/.rcs/.cs` 中文乱码 | 旧版 UTF-8 无 BOM，Word/记事本按本地编码打开会花；现已写 UTF-8 BOM。请重新处理生成文件；已有旧文件用编辑器选「UTF-8」打开另存即可 |
