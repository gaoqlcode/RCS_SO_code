## 2. 输出目录怎么统一（必读）

### 2.1 规则（界面与库一致）

默认路径：

```text
输入基目录 / 处理结果_<标记>
```

| 业务 | 基目录怎么来 | 标记函数（`OutPath.h`） |
|------|----------------|-------------------------|
| RCS | L0 文件夹 | `rcsResultTag(pol)` → `RCS_HH` |
| HRRP | L0 文件夹 | `hrrpResultTag(pol)` → `HRRP_HH` |
| 点频 | L0 文件夹 | `cwRcsResultTag(pol)` → `点频RCS_HH` |
| 后向散射 | RAW **所在目录**（`baseDirOfInput`） | `sigma0ResultTag()` → `后向散射` |
| 拼接 | 输入图目录 | `mosaicResultTag()` → `拼接` |

库侧：`lib/src/common/OutPath.h` 的 `resolveOutDir` / `*ResultTag`；  
界面侧：`gui/common/OutPath.h`（Qt 版）+ `OutDirField`。  
`req.outDir` 为空时，库内同样按上表拼默认目录。

### 2.2 `OutDirField`：各页共用控件

文件：`gui/common/OutDirField.h` / `.cpp`。

行为约定：

| 动作 | 调用 | 效果 |
|------|------|------|
| 选了/同步了输入路径 | `resetFromBase(base, tag)` | 丢掉用户覆盖，重算默认输出 |
| 换极化等 tag、点开始前 | `refresh(base, tag)` | 仅当未手改，或内容仍是上次自动值时更新 |
| 用户改字 / 点浏览 | 内部 `userEdited_=true` | 之后不轻易覆盖 |
| 取路径交给 Worker | `outDir_->text()` | 已 trim |

Page 里建行（以 HRRP 为例，其它页同型）：

```cpp
outDir_ = new OutDirField(this);
pathLay->addLayout(outDir_->createRow(pathBox));
outDir_->setPlaceholderHint(QStringLiteral("数据文件夹"),
                            QStringLiteral("HRRP_<极化>"));
// 占位符实际为：数据文件夹/处理结果_HRRP_<极化>
```

数据文件夹变更 / 开始处理：

```cpp
void HrrpPage::onDataFolderChanged(const QString &path)
{
    if (folderEdit_ && folderEdit_->text() != path)
        folderEdit_->setText(path);
    outDir_->resetFromBase(path, hrrpResultTag(polCombo_->currentText()));
}

void HrrpPage::onStart()
{
    // ...
    refreshDefaultOut();   // 内部 outDir_->refresh(...)
    HrrpParams p;
    p.dataFolder = folderEdit_->text().trimmed();
    p.outDir = outDir_->text();
    // ...
}
```

后向散射基目录来自文件父路径：

```cpp
outDir_->resetFromBase(baseDirOfInput(rawPath), sigma0ResultTag());
```

**不要**再在各 Page 里复制一套 `outDirUserEdited_ / lastAutoOut_ / onBrowseOut`。

### 2.3 和 `SharedDataSession` 的分工

| 对象 | 同步什么 |
|------|----------|
| `SharedDataSession` | L0 **输入**文件夹（预览 / RCS / HRRP / 点频） |
| `OutDirField`（每页一个） | 本页 **输出**目录（业务标记不同，故不跨页共用同一路径） |

## 3. GUI 线程骨架（必懂）

### 3.1 `ProcessWorker`：阻塞等人选点

`gui/common/ProcessWorker.cpp`：

```cpp
void ProcessWorker::provideSelection(const UserSelection &sel)
{
    QMutexLocker lk(&mutex_);
    selection_ = sel;
    haveSelection_ = true;
    selectionCv_.wakeAll();
}

bool ProcessWorker::waitForSelection(UserSelection &out)
{
    QMutexLocker lk(&mutex_);
    haveSelection_ = false;
    while (!haveSelection_ && !cancel_.load())
        selectionCv_.wait(&mutex_);
    if (cancel_.load())
        return false;
    out = selection_;
    haveSelection_ = false;
    return true;
}

void ProcessWorker::requestCancel()
{
    cancel_.store(true);
    QMutexLocker lk(&mutex_);
    selectionCv_.wakeAll();   // 把堵在 wait 里的 Worker 叫醒
}
```

库回调在 Worker 线程里同步调用 → Worker 进 `waitForSelection` 卡住 → UI 槽函数里**直接**调 `provideSelection`（不能 Queued 回 Worker，否则死锁）。

### 3.2 点频 Worker：把 Qt 参数变成库请求

`gui/modules/cw_rcs/CwRcsWorker.cpp`（整文件很短，建议通读）：

```cpp
void CwRcsWorker::startProcess()
{
    clearSelectionWait();

    CwRcsRequest req;
    req.dataFolder = ss(params_.dataFolder);  // QString → UTF-8 std::string
    req.pol = ss(params_.pol);
    // ...
    req.autoPick = false;   // 产品 GUI 必须 false，才会弹交互

    Callbacks cb;
    cb.onProgress = [this](int p, const std::string &m) { emitProgress(p, qs(m)); };
    cb.isCancelled = [this]() { return isCancelled(); };

    cb.onCornerConfirm = [this](..., InteractSelection &sel) {
        emit needCornerConfirm(...);          // Queued → UI 弹窗
        UserSelection qsel;
        if (!waitForSelection(qsel))          // Worker 阻塞
            return false;
        sel = toLibSel(qsel);
        return true;
    };

    cb.onTargetPick = [this](...) { /* 同上：emit → wait → toLibSel */ };

    CwRcsResponse resp;
    std::string err;
    if (!processCwRcs(req, resp, cb, &err)) {
        // 区分取消 / 失败
        return;
    }
    emit cwRcsReady(/* 曲线给 Page 画图 */);
    emit finishedOk();
}
```

`ss` / `qs` / `toLibSel` 在 `gui/common/RcsApiQt.h`。路径一律 UTF-8，不要 `toLocal8Bit()`。

## 4. 对外 API 长什么样

客户（和本仓库 GUI）只应 include：

```cpp
#include "rcs/rcs.hpp"
```

核心声明在 `sdk/include/rcs/rcs_api.h`：

```cpp
RCS_API bool processHrrp(const HrrpRequest &req, HrrpResponse &resp,
                         Callbacks &cb, std::string *err = 0);
RCS_API bool processRcs(...);
RCS_API bool processCwRcs(...);
RCS_API bool processSigma0(...);
RCS_API bool previewL0Folder(...);
```

约定（头文件注释原文要点）：

- 必须带 `Callbacks&`（进度 / 取消 / 选点）
- 默认 `autoPick=false` → 要实现对应回调
- 路径 UTF-8；`false` = 失败或取消，说明写 `*err`
- **客户 SDK 不含拼接** `processMosaic`

## 5. 库内信号处理（对着改算法时看这里）

### 5.1 两种去直流：轴不一样

`lib/src/signal/Preprocess.cpp`：

```cpp
// RCS / HRRP：每个距离门，沿脉冲维去均值
void Preprocess::removeDc(ComplexMatrix &data)
{
    for (int g = 0; g < data.nr; ++g) {
        std::complex<double> m{0, 0};
        for (int p = 0; p < data.np; ++p)
            m += data.at(g, p);
        m /= static_cast<double>(imax(1, data.np));
        for (int p = 0; p < data.np; ++p)
            data.at(g, p) -= m;
    }
}

// 点频：与 MATLAB RCS_DianPin.m 一致 —— 每个脉冲，沿距离向去均值
void Preprocess::removeDcPerPulse(ComplexMatrix &data)
{
    for (int p = 0; p < data.np; ++p) {
        std::complex<double> m{0, 0};
        for (int g = 0; g < data.nr; ++g)
            m += data.at(g, p);
        m /= static_cast<double>(imax(1, data.nr));
        for (int g = 0; g < data.nr; ++g)
            data.at(g, p) -= m;
    }
}
```

点频入口里的调用（`lib/src/cw_rcs/process_cw_rcs.cpp`）：

```cpp
// 与 RCS_DianPin.m 一致：每脉冲沿距离去直流（勿用 RCS/HRRP 的按门去直流）
Preprocess::removeDcPerPulse(data);
PulseCompress::apply(data, hdr.bwMHz, pulseWidthUs, fs, nullptr,
                      [&]() { return cancelled(cb); });
```

对照 MATLAB：`z = z - mean(z)` 作用在单个脉冲的距离维向量上。

### 5.2 峰附近裁剪（对齐 MATLAB 窗起点）

`lib/src/signal/Calibration.cpp`：

```cpp
void Calibration::cropAroundPeak(ComplexMatrix &data, std::vector<double> &profile,
                                 std::vector<double> &R, int peak, int cropN)
{
    if (data.nr <= cropN)
        return;
    const int half = cropN / 2;
    // 与 MATLAB RCS_207 对齐：1-based startG = pk0-half+1 → 0-based start = peak-half+1
    int startG = peak - half + 1;
    startG = ibound(0, startG, data.nr - cropN);
    // ... 拷贝 cropN 个门到新矩阵，替换 data / profile / R
}
```

改裁剪窗时同时核对 MATLAB 下标习惯（1-based vs 0-based）。

### 5.3 三级文本：UTF-8 BOM

`lib/src/io/Level3Text.cpp`：

```cpp
static bool writeTextUtf8(const std::string &path, const std::string &text, std::string *err)
{
    // 带 UTF-8 BOM：Windows 记事本/Word 才能自动按 UTF-8 打开
    static const char kBom[] = "\xEF\xBB\xBF";
    std::string out;
    out.reserve(3 + text.size());
    out.append(kBom, 3);
    out.append(text);
    return writeFileAll(path, out.data(), out.size());
}
```

`saveHrrp` / `saveRcs` / `saveCwRcs` / `saveCs` 都走这里。Linux 用带 BOM 的 UTF-8 也没问题。

## 6. `lib/src` 目录地图

| 目录 | 主要文件 | 干什么 |
|------|----------|--------|

### 7.1 十字线吸附曲线

`gui/ui/InteractivePlotWidget.cpp`：

```cpp
bool InteractivePlotWidget::snapToCurve(double dataX, double &sx, double &sy) const
{
    const int n = qMin(x_.size(), y_.size());
    if (n <= 0)
        return false;
    int best = 0;
    double bestDx = std::abs(x_[0] - dataX);
    for (int i = 1; i < n; ++i) {
        const double dx = std::abs(x_[i] - dataX);
        if (dx < bestDx) { bestDx = dx; best = i; }
    }
    sx = x_[best];
    sy = y_[best];
    return true;
}
```

鼠标移动时用吸附后的 `(sx,sy)` 画十字线并延到坐标轴，状态栏显示数值。

## 8. MATLAB ↔ C++ 对照（读代码时别搞混）

| 点 | MATLAB | 本仓库 C++ |
|----|--------|------------|
| 点频去直流 | `RCS_DianPin.m`：每脉冲 `z-mean(z)` | `removeDcPerPulse` |
| RCS/HRRP 去直流 | 按距离门沿慢时间 | `removeDc` |
| 峰裁剪起点 | 1-based `pk-half+1` | `startG = peak - half + 1` |
| σ⁰ 理论值 | 部分脚本把 dBsm 当线性用 | `10^(dB/10)` 转线性（物理正确；数值可能与旧脚本差约 5.6 dB） |
| 三级中文 | 视编辑器 | UTF-8 BOM |

## 9. 编译完成后产物在哪

一键脚本编完会做三件事：编库 → 打 `sdk/lib` → **deploy 发布目录**。

| 平台 | 开发产物 | 可发布目录 |
|------|----------|------------|
| Linux | `build_linux/bin/RCS`、`build_linux/lib/` | `deploy/linux_<arch>/`（`run_RCS.sh`） |
| Windows | `build_win\bin\RCS.exe` | `deploy\win64\`（双击 `RCS.exe`） |

```bash
./scripts/build_linux.sh          # 末尾自动 ./scripts/deploy_linux.sh
```

```powershell
.\scripts\build_win.ps1           # 末尾自动 deploy_win.ps1
```

只重新打包（已编过）：

```bash
RCS_BUILD_DIR=build_linux ./scripts/deploy_linux.sh
```

```powershell
$env:RCS_BUILD_DIR="build_win"; .\scripts\deploy_win.ps1
```

Linux 发布目录结构（`run_RCS.sh` 已设好 `LD_LIBRARY_PATH` / `QT_PLUGIN_PATH`）：

```text
deploy/linux_x86_64/
  bin/RCS
  bin/rcs_cli
  lib/librcs_proc.so*   + Qt / ICU 等
  plugins/platforms/libqxcb.so
  run_RCS.sh
  run_cli.sh
  README.txt
```

Windows：`deploy/win64/` 平铺 `RCS.exe`、`librcs_proc.dll`、Qt DLL、`platforms/`、MinGW 运行时。

## 10. 动手核对（对着源码改一两处）

1. **点频去直流**：在 `process_cw_rcs.cpp` 临时改回 `removeDc`，对比曲线后再改回 `removeDcPerPulse`。  
2. **输出目录**：换 L0 文件夹看输出是否变成 `…/处理结果_HRRP_HH`；手改输出后再换极化，确认手改路径不被覆盖；清空输出框再换极化，应恢复自动值。  
3. **后向散射输出**：选 RAW 后应自动填 `RAW同目录/处理结果_后向散射`。  
4. **交互死锁**：在 `HrrpPage::onNeedCorner` 把 `provideSelection` 改成 Queued（仅本地试）会卡死——再改回直接调用。  
5. **BOM**：三级文件头应为 `EF BB BF`。  
6. **吸附**：在 `snapToCurve` 打断点，拖鼠标看 `best` 下标变化。
